SOBRE O PROJETO:
O BIOQUIZ é um jogo de perguntas e respostas sobre Biologia, desenvolvido em Dart para ser executado no terminal.

O objetivo é testar os conhecimentos do jogador sobre temas como célula, organelas, genética, fotossíntese e corpo humano.

O jogador informa seu nome e responde a cinco perguntas, escolhendo entre as alternativas A, B, C ou D. Ao final, o programa apresenta a pontuação e uma mensagem de desempenho.

EXEMPLOS DE PERGUNTAS:

**Qual é a unidade básica da vida?**

- A) Átomo
- B) Célula
- C) Tecido
- D) Órgão

Resposta correta: B) Célula.

TECNOLOGIAS UTILIZADAS:
- Dart
- Entrada e saída de dados pelo terminal
- Listas e estruturas de repetição
- Condicionais e funções

COMO EXECUTAR:
1. Abra o terminal na pasta do projeto.
2. Execute o comando:

```bash
dart run
```

3. Digite seu nome e comece a responder às perguntas.

USO DE INTELIGENCIA ARTIFICIAL:
O ChatGPT foi utilizado como ferramenta de apoio durante o desenvolvimento do projeto, auxiliando na organização do código, na explicação dos conceitos de Dart e na orientação dos passos de criação e execução.

O código foi adaptado e executado para verificar seu funcionamento, incluindo a validação das respostas e o cálculo da pontuação.
